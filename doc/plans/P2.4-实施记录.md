## 2. 关键设计决策

| 决策 | 内容 | 理由 |
|---|---|---|
| 组件一份两用 | W1 存装箱 struct = W2 的 IComponent/ITag | Object ≈ Entity 定案；Baker 直通零映射 |
| 事务 op 统一 JSON | op 里组件值为 JsonElement（经 Schema 转换） | UI 强类型与 MCP 纯 JSON 收敛为同一数据形态——门禁 1 的基础 |
| JsonElement 手写相等 | Add/Set op 按 GetRawText 比较 | record 默认相等对不同 document 来源失效 |
| Undo 记绝对旧值 | 操作级逆数据（删除=子树快照），Undo 与中间历史无关 | 反复 undo/redo 恒正确；Redo 重放规范化 ops（自动分配 Id 已落实） |
| hash 混字段原始值 | SplitMix64 直接混字段数值而非 JSON 文本 | 不依赖 S.T.J 浮点格式版本 |
| SetPrototypeOp 防环 | 不能把自己/子孙设为原型；解析链 visited 防环 | 数据完整性 |
| 显式删除也是 override | RemoveComponent 对继承组件 → 记 overrides（removed-override） | Prefab "可解释"需回答"为什么没有" |

## 3. 已知边界（留给 P3+）

- **原型变更不脏化实例**：改原型后，已烘焙实例不会自动重烘（无依赖传播）。增量 Baker 只认 per-object 版本——P3 Baker Spine 引入依赖图解决。
- **关系不进 W2**：BakedObject.Relations 只是数据；映射到 W2 ILinkComponent 由游戏侧消费端决定（框架未内置）。
- **RuntimeBundle 反射写组件**：MakeGenericMethod 仅在场景装载时发生（非热路径，句柄有缓存）；NativeAOT 场景待 P3 用源生成直发替代。
- **持久化不含 undo 历史**：场景文件即 Artifact，会话历史不落盘（符合预期）。
- **嵌套实例化**：支持任意深度原型链，但 UI 便捷层未提供"实例化"一键构造（测试演示标准三步：Create + SetPrototype [+ 覆盖]）。
